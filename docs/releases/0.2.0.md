# Tachyon 0.2.0: Sprint 2 test build

A test build of Tachyon, a web browser for Windows 95 that aims to handle today's web. It can't draw web pages yet: it fetches them over HTTPS and shows their HTML as a document tree, the way a browser's developer tools do. Rendering arrives in Sprint 3.

## Download

| File | What it is |
|---|---|
| `tachyon-0.2.0-win95-setup.exe` | **The installer.** Run it on Windows 95: it installs Tachyon in `C:\Program Files\Tachyon` with Start menu and desktop shortcuts, and Add/Remove Programs removes it again. |
| `tachyon-0.2.0-win95.iso` | A CD-ROM image with `SETUP.EXE` and the programs, for virtual machines |
| `tachyon-0.2.0-win95.img` | A 1.44 MB floppy image with `TACHYON.EXE`, which runs without installing |
| `tachyon-0.2.0-win95.zip` | The programs, to copy anywhere |
| `tachyon-0.2.0-win95-symbols.txt` | For developers: turns the addresses in a crash report back into function names |

## Requirements

- Windows 95, any release, with nothing else installed: Tachyon uses only what comes with Windows 95.
- A Pentium Pro, Pentium II or newer CPU (or an emulator set to one). The original Pentium, Pentium MMX and AMD K6 aren't supported yet.
- TCP/IP over a network card or Dial-Up Networking, and **the right date and time**: certificates can't be checked with a wrong clock.

## What it does

- Fetches pages over HTTP and HTTPS, with TLS 1.2 and 1.3 checked against Mozilla's root certificates (Sprint 1).
- Parses HTML exactly as today's browsers do and shows the document tree: click a [+] to open an element, or press Ctrl+U for the page's source (Sprint 2).
- Keeps a log, `TACHYON.LOG`, with a report when it crashes: Help > View Log opens it.
- `FETCH.EXE` fetches a page from the MS-DOS Prompt. `EXPORTS.EXE` lists the functions your copy of Windows provides, which helps us check that Tachyon only uses what Windows 95 really has.

## Known limits

- No rendering, images, JavaScript, forms or cookies yet: see the [sprint board](https://github.com/georgemathieson/Windows-95-modern-browser/blob/v0.2.0/docs/SPRINTS.md).
- Chinese, Japanese and Korean pages in their older encodings come out garbled.
- This is the first build to go to real Windows 95. It passes its tests under Wine, which isn't the same thing.
